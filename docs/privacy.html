Privacy

Effective for the open-source MIT release.

Samurai Agent is a local VS Code / Open VSX extension. It does not phone home and does not ship usage analytics.

When you run a review or debug session, prompts and the minimum required code context are sent only to the LLM provider you configured (OpenAI, Google Gemini, or Anthropic) using the API key you stored in VS Code Secret Storage. That provider’s privacy policy applies to those requests.

API keys are stored in VS Code Secret Storage on your machine. Provider and model name preferences are stored in local settings JSON without the key.

The extension does not modify your project source files. Sandboxed analysis, when used, runs against copies or generated scripts only.

Questions: open an issue on GitHub.
